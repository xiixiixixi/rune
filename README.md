# 轻截

轻截是一款中文 Mac 截图工具。它是在 BetterShot 开源代码基础上独立改造的自有版本，不属于 BetterShot 官方产品，也不连接原项目的更新服务。

软件采用本地优先设计：截图、滚动拼接、文字识别和隐私打码都在当前 Mac 上完成；默认不上传截图、不发送识别文字、不收集使用数据。

## 主要功能

- 区域截图、全屏截图、窗口截图
- 滚动截图，可把人工滚动的页面拼成长图
- 连续截图：连续拍摄、固定 10 张、每 5 秒拍摄
- 全屏录制和区域录制
- 中文和英文文字识别、二维码与条码识别
- 手机号、邮箱、身份证号和人脸自动打码
- 箭头、矩形、文字、模糊、聚光灯等标注工具
- 截图美化、贴图、历史记录和多显示器支持

## 默认快捷键

| 功能 | 快捷键 |
|---|---|
| 区域截图 | `⇧⌘E` |
| 全屏截图 | `⇧⌘S` |
| 窗口截图 | `⇧⌘W` |
| 文字识别 | `⇧⌘O` |
| 取色 | `⇧⌘C` |
| 录屏 | `⇧⌘2` |
| 连续截图 | `⇧⌘B` |

所有快捷键都可以在“设置 > 截图”里修改。

## 编译和启动

```bash
make run
```

常用命令：

| 命令 | 作用 |
|---|---|
| `make build` | 编译调试版，并使用固定的本地身份签名 |
| `make release` | 编译同时支持 Apple 芯片和 Intel 芯片的正式版 |
| `make run` | 编译并启动轻截 |
| `make dmg` | 生成本地测试安装包 |
| `cd CaptureKit && swift test` | 运行截图核心的自动检查 |

首次启动后，需要在“系统设置 > 隐私与安全性 > 屏幕与系统音频录制”中允许轻截。之后请继续用 `make build` 或 `make run` 编译，它们会保持同一个本地应用身份，避免每次改代码后都被系统当成一款新软件。

## 更新方式

轻截没有自动更新，也不会访问 BetterShot 官方发布页。新版本由项目所有者自己修改、编译和安装。

## 中文说明

面向使用者的应用名称、菜单、设置、按钮、提示、权限说明和文件名均为中文。`macOS`、`PNG`、`MP4` 等系统名或文件格式名保留原写法。

代码里的 `BetterShot.xcodeproj`、`BetterShotApp.swift` 等名称只是继承下来的内部工程名，不会作为产品名称展示。保留这些内部名称可以减少无意义的工程风险。

## 隐私

- 文字识别使用 Apple Vision，在本机执行。
- 文字识别结果只复制到本机剪贴板，不会自动发给翻译网站。
- 软件不会自动上传截图；上传能力只有在使用者明确操作并配置后才会联网。
- 软件不包含遥测和使用数据上报。
