# 轻截

一个入口的 Mac 截图工具：按 `⇧⌘A`，截完之后所有功能才出现在你面前。

在开源项目 [BetterShot](https://github.com/KartikLabhsetwar/better-shot)（BSD-3）基础上独立改造，本地优先：截图、滚动拼接、文字识别、隐私打码全部在你的 Mac 上完成，不上传、不联网、不收集数据。

## 下载

到 [Releases](https://github.com/xiixiixixi/qingjie/releases/latest) 下载最新 `qingjie-x.x.x.dmg`，双击打开，把"轻截"拖进 Applications 文件夹。

第一次使用：
1. 右键点"轻截" → 打开 → 再点"打开"（本地签名，只需这一次）
2. 首次截图时在系统设置中允许屏幕录制权限

## 用法：就记"点"还是"拖"

```
⇧⌘A → 出现选区界面
  拖一块        = 自定义区域
  点某个窗口    = 截整窗
  点桌面空白    = 截全屏
     ↓
冻结画面 + 底部工具栏（功能这时才出现）：
  [选择][矩形][箭头][文字][马赛克][编号] [色板·粗细] [撤销]
  | [识别文字][滚动长图][连拍][复制][贴图] | [取消] [保存]
```

- **识别文字**：图上文字变可选块——点一块复制一块，拖一片复制一段
- **滚动长图**：当前选区转滚动截图，滚到底自动拼接
- **连拍**：对当前选区连续抓拍，实时计数，点关闭停止
- **贴图**：钉在桌面上，拖角按比例缩放
- **保存**：标注 + 美化边框一起烘焙进成品（Enter 保存 / Esc 零残留）

隐藏快捷键：`⇧⌘B` 连拍中停止、`⇧⌘C` 取色、`⇧⌘2` 录屏。

## 功能一览

- 三合一截图入口：区域 / 窗口 / 全屏，截图时顺手选
- 确认模式：标注完点保存才落盘，取消零残留
- 滚动截图、连拍、录屏、贴图、OCR（中英文 + 条码）
- 手机号 / 邮箱 / 身份证号 / 人脸自动打码
- 截图美化（渐变边框）、多显示器、历史记录
- 26 项单元测试，Universal 2（Apple Silicon + Intel）

## 系统要求

macOS 14.0+

## 编译

```bash
make build    # 调试版
make release  # 正式版（双架构 + 本地签名）
make dmg      # 安装包
cd CaptureKit && swift test   # 单元测试
```

## 隐私

- 文字识别使用 Apple Vision，在本机执行，结果只进本机剪贴板
- 不自动上传截图，不包含遥测和使用数据上报
