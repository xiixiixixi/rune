# Rune

一个入口的 Mac 截图工具：按 `⇧⌘A`，截完之后所有功能才出现在你面前。

在开源项目 [BetterShot](https://github.com/KartikLabhsetwar/better-shot)（BSD-3）基础上独立改造，本地优先：截图、滚动拼接、文字识别、隐私打码全部在你的 Mac 上完成，不上传、不联网、不收集数据。

## 下载

到 [Releases](https://github.com/xiixiixixi/rune/releases/latest) 下载最新 `Rune-x.x.x.dmg`，双击打开，把"Rune"拖进 Applications 文件夹。

Rune 会在启动时静默检查新版本，常驻期间每小时复查；只有发现新版时才提示更新。它只查询 Rune 自己的 GitHub Release，不连接 BetterShot，也不会上传截图或使用数据。

第一次使用：
1. 右键点"Rune" → 打开 → 再点"打开"（本地签名，只需这一次）
2. 首次截图时在系统设置中允许屏幕录制权限

## 用法：就记"点"还是"拖"

```
⇧⌘A → 出现选区界面
  拖一块        = 自定义区域
  点某个窗口    = 截整窗
  点桌面空白    = 截全屏
  按住 ⌥ 松手   = 反转去向（设置里选的那一项反过来）
     ↓
时间冻结确认（功能这时才出现）：
  截中的位置原地保持清晰，四周冻结变暗，边缘有快门波纹
  [选择][方框][箭头][文字][打码][聚光][编号] [色板·粗细] [撤销]
  | [识字][长图][连拍][保存][贴图] | [取消] [复制]
  工具台自动贴在选区下方；放不下时翻到上方
```

设置 → 通用 → 行为 → **框选后**可以改成「直接复制」：框完即进剪贴板与素材库，
不弹确认台、不打断手上的事。

- **识别文字**：图上文字变可选块——点一块复制一块，拖一片复制一段
- **滚动长图**：当前选区转滚动截图，滚到底自动拼接
- **连拍**：对当前选区连续抓拍，实时计数，点关闭停止
- **贴图**：钉在桌面上，拖角按比例缩放
- **贴剪贴板**：`⇧⌘V` 把剪贴板里的图直接贴到屏幕上，不用先截图
- **复制**：只进剪贴板，**不往桌面丢文件**；也会记进素材库，随时能补存
- **拖出去**：直接拖「复制」按钮进聊天窗口/访达，或在选区内按住 `⌥` 拖动
- **保存**：标注 + 美化边框一起烘焙进成品（`⌘S` 保存 / `⇧⌘Enter` 复制并保存）
- **取消**：Esc 零残留，不写文件、不建历史

确认台上的键盘：`Enter` 默认仅复制（设置 → 通用 → 行为可改成复制并保存 / 仅保存），
`⇧⌘Enter` 复制并保存，`⌘S` 保存，空白处双击等同 `Enter`。

隐藏快捷键：`⇧⌘B` 连拍中停止、`⇧⌘C` 取色、`⇧⌘2` 录屏、`⇧⌘V` 贴剪贴板。

## 功能一览

- 三合一截图入口：区域 / 窗口 / 全屏，截图时顺手选
- 时间冻结确认：选区原位高亮、外围压暗，标注完点保存才落盘，取消零残留
- 复制与保存分开：只复制就只进剪贴板 + 素材库，桌面不会被塞满
- 截图可直接拖进聊天窗口、浏览器或访达（图像数据 + 文件两种表示都给）
- 快速模式：框完即走，或按住 ⌥ 临时切换
- 贴剪贴板：复制过的图随时钉回屏幕
- 滚动截图、连拍、录屏、贴图、OCR（中英文 + 条码）
- 手机号 / 邮箱 / 身份证号 / 人脸自动打码
- 截图美化（渐变边框）、多显示器、历史记录
- 74 项单元测试，Universal 2（Apple Silicon + Intel）

## 系统要求

macOS 14.0+

## 编译

```bash
make build    # 调试版
make release  # 正式版（双架构 + 本地签名）
make dmg      # 安装包
cd CaptureKit && swift test   # 单元测试
```

## 隐私

- 文字识别使用 Apple Vision，在本机执行，结果只进本机剪贴板
- 不自动上传截图，不包含遥测和使用数据上报
- 在线更新只查询 Rune 自己的 GitHub Release；检查自动进行，已是最新版时完全静默
